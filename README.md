# Продуктовая корзина Андрея Рудомахи

Лендинг-статья, статический сайт на GitHub Pages (ветка `main`, корень репозитория).

## Файлы
- `index.html` — сама статья
- `style.css` — оформление статьи
- `app.js` — карусели; ссылка на оплату в переменной `PAY_URL` в начале файла
- `oferta.html`, `privacy.html`, `doc.css` — оферта и политика конфиденциальности
- `img/case01.jpg` … `case13.jpg` — кейсы до/после (первая карусель показывает все, вторая — женские)
- `img/meme-*.jpg` — мемы в тексте

Изменения в `main` публикуются автоматически через 1–2 минуты.
